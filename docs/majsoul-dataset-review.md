# 작혼 옥탁·왕좌탁 패보 조사

2026-10-29 확인. 제품 의존성 추가나 모델 학습은 수행하지 않았다.

## 실제 접근 확인

[Hugging Face 데이터셋](https://huggingface.co/datasets/nikketryhard/tenhou-houou-mjai)의 API에서 `majsoul-jade-2019.tar`~`2026.tar`, `majsoul-throne-2019.tar`~`2026.tar` 총 16개 파일, 30,755,184,640 bytes(약 30.76GB)를 확인했다. 천봉 파일은 조사 대상에서 제외했다. README에 빠진 2026 파일도 API에는 있다.

각 파일의 앞 512KiB를 HTTP Range로 요청해 모두 206 응답을 받았다. 총 8MiB만 받고 각 파일의 처음 완전한 10대국을 zstd 해제·JSON 파싱했다. 첫 구간의 편의 표본이므로 무작위 표본이나 전체 품질 검증은 아니다. TAR를 디스크에 풀지 않고 멤버를 메모리로 읽었다. 원본 prefix는 Git 제외 `.research/paipu-samples/`에만 보관한다. 압축 해제용 zstandard 0.25.0은 PyPI 공식 휠 SHA256 검증 후 연구용 폴더에만 배치했다.

## 샘플 확인 결과

- 160대국, 1,665국, 타패 81,473건, 쯔모 78,263건을 JSON 이벤트로 확인했다.
- 160개 모두 시작·종료 이벤트가 있고 초기 손패는 네 좌석이다. 초기 손패와 쯔모는 가려지지 않은 기록이다.
- 치·퐁·암깡·가깡·대명깡·리치·화료·유국 이벤트가 실제로 들어 있다.

옥탁 2021~2026 샘플은 첫 쯔모가 초기 14장에 포함되고 첫 타패부터 시작한다. 별도 dora 이벤트가 없는 이유와 다른 필드에 포함되는지는 추가 확인이 필요하다. 깡 수와 도라 수가 반드시 같아야 하는 것은 아니지만 이 형식 차이를 무시하면 학습 관측을 잘못 만들 수 있다. 왕좌탁도 완전한 정합성을 보증하지 않는다.

탁 구분은 배포자의 폴더·파일 분류에 근거한다. 확인한 start_game 필드에는 탁 ID·플레이어 단위 계급이 없으므로 상위 유저 등급이나 원본 출처를 개별 검증한 것은 아니다. 4인전은 손패 배열로 확인했지만 동풍/반장 구분은 원본 메타데이터와 함께 확정해야 한다.

## 추가 확보 경로

- [MajSoul Stats](https://amae-koromo.com/): 날짜·탁·유저로 대국 목록 탐색. 목록·점수 정보와 학습에 필요한 전체 행동 원문은 구분해야 한다.
- [공식 소스의 탁 ID](https://github.com/SAPikachu/amae-koromo/blob/master/src/data/types/gameMode.ts): 4인 옥탁 반장 12, 왕좌탁 반장 16, 옥탁 동풍 11, 왕좌탁 동풍 15. 3인 ID는 별도다.
- [수집·변환 도구 문서](https://github.com/NikkeTryHard/tenhou-to-mjai/blob/main/docs/majsoul-scraper.md): 목록 UUID 탐색 → 작혼 원본 protobuf 다운로드 → MJAI 변환. 원본 다운로드에는 계정이 필요하다. 도구 문서만 확인했고 로그인·직접 수집은 실행하지 않았다.
- [MajsoulPaipuConvert](https://github.com/jeff39389327/MajsoulPaipuConvert): 개발자가 CN 계정 필요·4인 지원이라고 명시한다. 설치·로그인은 실행하지 않았다.

## 이용 조건과 다음 검증

데이터셋 라이선스 표기는 `other`다. 배포 카드의 도구 Apache-2.0 설명을 패보 자체의 학습·재배포 허가로 볼 수 없다. 권리 설명은 천봉 중심이어서 작혼 원본에 관한 조건은 명확하지 않다. 배포 가능·상업 사용 가능으로 확정하지 않았다.

먼저 왕좌탁 소량을 대상으로 원본 UUID·탁 ID·규칙 메타데이터를 대조하고, 이벤트 상태 재구성·합법 행동·점수 검증을 해야 한다. 옥탁의 14장 시작 및 도라 표현은 별도 변환 검증이 필요하다. 학습 입력은 자기 손패와 그 시점까지의 공개 정보만 사용하고 상대 손패·미래 쯔모를 제거한다. 유저 이름은 제거하고 같은 대국 UUID가 학습·검증·테스트에 중복되지 않게 분리한다. 사람의 타패 일치율은 측정 가능하지만 사람 대비 대국 실력과 동일하지 않다.

집계 증거: `docs/validation/majsoul-paipu-sample-audit.json`. 원본 유저명·패보 UUID는 저장소 집계에서 제외하고 파일 식별자는 SHA256으로 기록했다.
